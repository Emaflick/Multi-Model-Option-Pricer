# Roadmap and validation plan — phases, scope, acceptance gates

Tolerances are absolute on prices with F = 100 unless stated. "3SE" = within 3 Monte Carlo standard errors.
Each phase: the mathematics is written up in `docs/derivations/` → the code and its unit tests are written
against it → the gates below are re-checked by an independent re-implementation (`tests/validation/`,
reports in `docs/validation/`) → the phase is committed. A phase is done only when all its gates pass.

---

## Phase 0 — Setup & data
- `pip install -e .[dev]`; pytest markers (`slow`); ruff config; `git init` if needed.
- `scripts/fetch_spx.py`: download the current ^SPX option chain via yfinance (all expiries 1w–2y), save raw to
  `data/raw/spx_<YYYYMMDD_HHMM>.parquet` with spot and timestamp. Run it once.
- `data.py` cleaning: drop zero bid, (ask−bid)/mid > 0.5, zero open interest; mid prices; keep OTM options.
- `market.py`: per expiry, regress (C − P) on K for near-ATM strikes: C − P = DF·F − DF·K → DF = −slope,
  F = intercept/DF. No hard-coded r or dividend yield.

**Gates:** parity regression R² > 0.999 on each kept expiry (drop and log expiries that fail) · implied DF in (0.8, 1].

## Phase 1 — BSM (Black-76)
- Price, delta, gamma, vega, theta (vectorised). Implied-vol solver: Newton on vega with Brent fallback,
  bracketed by no-arbitrage bounds.

**Gates:** put-call parity < 1e-12 · IV round-trip < 1e-10 for σ∈[0.05, 1], T∈[0.02, 5], |ln(K/F)| ≤ 3σ√T ·
greeks vs central finite differences, relative error < 1e-5.

## Phase 2 — Heston
- Characteristic function in the Albrecher et al. (2007) "little trap" form.
- Pricing: **COS** (Fang–Oosterlee 2008; price puts, calls via parity; cumulant truncation range, N=256)
  and **Lewis (2000)** single-integral (scipy.quad) as an independent check.
- MC: Euler full truncation and Andersen (2008) QE (ψc=1.5).

**Gates:** COS vs Lewis < 1e-6 over K∈[60,150], T∈[0.1, 3] · ξ→1e-4 limit equals BSM with
σ² = (1/T)∫₀ᵀ v(t)dt, v(t)=θ+(v0−θ)e^{−κt}, < 1e-5 · QE MC vs COS within 3SE (2e5 paths) ·
Euler bias shrinks with Δt (figure) · one Feller-violating parameter set included.

## Phase 3 — SABR
- Hagan et al. (2002) lognormal implied-vol expansion; β fixed = 1 for SPX (record in DECISIONS.md).
- MC check: log-Euler on F with lognormal α.

**Gates:** ν→0, β=1 → flat vol α (< 1e-10) · Hagan vs MC within 3SE for T ≤ 1, |ln K/F| ≤ 0.2 ·
figure showing where the Hagan approximation degrades (long T / wings).

## Phase 4 — Exotics (MC under BSM and Heston)
- **Barrier** (down-and-out / up-and-out call/put + knock-in via parity): Reiner–Rubinstein (1991) closed form
  under BSM as oracle; MC with Brownian-bridge crossing correction for continuous monitoring; discrete
  monitoring with Broadie–Glasserman–Kou (1997) shift e^{±0.5826σ√Δt}.
- **Asian** (arithmetic, discrete fixings): geometric closed form (Kemna–Vorst 1990) used as control variate.
- **Autocallable** (mono-asset): annual/quarterly observations, autocall barrier 100%, coupon barrier,
  capital-protection barrier 60% at maturity (European), optional memory coupon.

**Gates:** in + out = vanilla on the same paths (< 1e-12) · barrier MC (BB-corrected) vs RR within 3SE ·
geometric-Asian MC vs Kemna–Vorst within 3SE · report variance-reduction factor of the CV ·
autocallable priced under BSM (ATM vol) vs calibrated Heston: report the difference and explain it
(skew at the protection barrier, forward skew, vol-of-vol).

## Phase 5 — Calibration to SPX
- Heston on the whole surface: minimise IV errors (or price errors weighted by 1/vega²) with
  `scipy.optimize.least_squares` (TRF, bounds), multi-start (≥ 8 starts), COS pricer inside.
- SABR per expiry (α, ρ, ν), β = 1.
- Diagnostics: IV RMSE in vol points per expiry, fitted-vs-market smile figures, Feller ratio 2κθ/ξ²,
  parameter sensitivity to starting point.
- No-arbitrage checks on the market surface: calendar (total variance non-decreasing in T at fixed k),
  butterfly (call prices convex in K).

**Gates:** synthetic round-trip (data generated from known Heston params + 0.3 vol-pt noise) recovers params
within a documented tolerance · real-data fit completes, RMSE table produced, no NaNs.

## Phase 6 — Benchmark MC vs closed form
- Vanilla under BSM and Heston: |error| and SE vs N (1e3…1e6), log-log slope; time vs error.
- Plain MC vs antithetic vs control variate vs Sobol QMC (scipy.stats.qmc).

**Gates:** plain-MC slope in [−0.6, −0.4] · every figure regenerated by `scripts/run_benchmarks.py`.

## Phase 7 — Paper
- A write-up of the whole project in `paper/` (LaTeX): models, numerical methods, data, validation,
  calibration and benchmark results, limitations. Every number is taken from a script output in this repo.
